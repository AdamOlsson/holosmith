**Verdict: BLOCK** — one P1 (the new `ok <case>` line reports a skip as a pass, and the change's own docs say the opposite), plus P2s.

### Spec axis

- **S1 · P2 — `HolosmithSpec.md:408` (V2 cell) over-claims the test's reach.** "`tests/doctor.rs` every arm of it over a real git" — only the passing arm uses the machine's git (`crates/holosmith/tests/doctor.rs:435-441`, `tools_with_real_git`); the refusing arms use a git shim (`doctor.rs:445-451` `tools(&wrong,"2.43.0")`, `doctor.rs:466-477` `tools(&dir,"2.37.4")`; see `doctor.rs:87-96`). ADR-0054 says the same ("a real git for the trial"). *Fix:* "…`tests/doctor.rs` (the passing arm on the machine's own git, the refusing arms over a git shim)".
- **S2 · P2 — V3/V4/V5 were not re-measured, and neither the cells nor ADR-0055 says so.** `HolosmithSpec.md:409-411` say "re-run by hand from `docs/build.md`'s credential section", which reads as an instruction/provenance; `docs/notes.md:1461-1464` (added by this diff) states flatly that V3–V5 *cannot* be re-run here ("no provider key anywhere") and that the cells quote HS-040's recorded run. Acceptance bullet 1 ("V1–V10 are each run on a real Docker host") is therefore met by fresh runs for V1, V2, V6–V10 and only via HS-040's earlier run for V3–V5. `docs/adr/0055-…:79` ("This story took none: all ten runnable rows passed") and its row table (`:34`) let a future story read HS-046 as having measured all ten. *Fix:* in each of the three cells, replace "re-run by hand from …" with "not re-measured in this story (no provider key exists here): this quotes HS-040's by-hand run; to re-measure, follow `docs/build.md`'s credential section", and add one sentence to ADR-0055's Consequences saying the same.
- **S3 · P2 — a row numbered V12 would be invisible to the gate.** `scripts/verify.sh:437` matches only `V(1[01]|[1-9])` and the loop at `:443` hard-codes 1–11, so adding `| V12 | … | not yet run |` leaves the count at 11 and the row unread — it passes. That contradicts `scripts/verify.sh:424-426` and `docs/adr/0055-…:69-70` ("a row a later story adds is measured by the same rules without an edit here"). Nothing is wrong today; the documented property is not the code's. *Fix:* `rows="$(grep -E '^\| V[0-9][0-9]* \|' "$spec" || true)"`, iterate `for n in $(printf '%s\n' "$rows" | sed -n 's/^| V\([0-9][0-9]*\) |.*/\1/p')`, and keep `check "$name/rows" 11 "$n"` so raising the count stays a deliberate edit.
- **S4 · P2 — a failed row that records no fallback passes the gate.** `scripts/verify.sh:460-462` accepts `**fail**` without checking the thing acceptance bullet 2 requires ("on failure which fallback was taken"). *Fix:* after the verdict check, `if printf '%s\n' "$cell" | grep -q '\*\*fail'; then printf '%s\n' "$cell" | grep -qi 'fallback' || fail "$name/V$n" "V$n failed with no fallback recorded: $cell"; assertions=$((assertions+1)); fi`.
- **S5 · P2 — "runs first" is true of `serve_cases`, not of the phase.** `scripts/verify.sh:5156` boots the server before the loop, so `build.md:308-309`'s "a rotted table should cost a second" holds only against the Docker cases. *Fix:* say "runs first in `serve_cases` (the shared boot has already happened)".

### Standards axis

- **T1 · P1 — `ok <case>` is printed whether the case measured anything or skipped.** `scripts/verify.sh:5157-5161` prints unconditionally; 33 skip sites `printf 'SKIP …'; return 0` (e.g. `:507`, `:1184`, `:1944`, `:2492`, `:2665`, `:2908-2920`, `:4284`, `:4591`, `:4686`, `:4818`, `:4966-4974`). On a hub-class machine or without `python3`/image, a skipped case now logs `SKIP case_x: …` immediately followed by `ok case_x`. That contradicts the change's own three claims — `scripts/verify.sh:31` ("once it passes"), `docs/build.md:337-338` ("when it passes … names what it proved"), `docs/notes.md:1457` — and `docs/build.md:514` ("each case prints one `SKIP` line and the run passes"). It matters exactly where the story says it does: `case_internet_toggle` skips its `on` half when `hs_egress` is not running (`:2665`) and `case_preview` skips its V7 half without daemon/image/python3 (`:2908-2921`), yet V6 (`HolosmithSpec.md:412`) and V7 (`:413`) cells rest on those cases and the run now prints `ok` for them. *Fix:* `case_skipped=0` before `"$case_fn"`, `case_skipped=1` before each `return 0` (or one `skip "$name" "why"` helper replacing the 33 sites), and in the loop `[ "$case_skipped" = 1 ] || printf 'ok %s\n' "$case_fn"`. Until then, the three doc sentences must not say "when it passes".
- **T2 · P2 — `docs/build.md:339` is a reflow orphan.** "needs a setting the" sits alone on a line mid-sentence (the paragraph is otherwise ~100 cols). *Fix:* reflow `:335-344`.
- **T3 · P2 — second spelling of the glossary's own term.** `GLOSSARY.md:704-711` standardises **Verification table** (`_Avoid_: Checklist, test matrix, verification report, phase-1 report`), while the diff adds three new uses of the other name: `scripts/verify.sh:417`, `docs/build.md:304`, `docs/adr/0055-…:3`. *Fix:* add "vertical-slice table, vertical-slice rows" to that entry's `_Avoid_` and use the glossary word in those three places. *Reading taken on the `Finding` entry's `_Avoid_: Result` (`GLOSSARY.md:698`):* it forbids "Result" as a name for a **Finding**; the new entry explicitly distinguishes the spec's column from a Finding, so it creates no second spelling there — the inconsistency is the vertical-slice wording, not the Result wording.
- **T4 · P2 — two imprecise statements in the new landmine section.** `docs/notes.md:1459` says `ok serve: N cases` "is still the last line of the loop" — it is printed after the loop and after `case_no_cors_header`/`stop_serve` (`scripts/verify.sh:5164-5167`). `docs/notes.md:1452-1453` says a `|` in a cell "would silently move the field the verdict is looked for in" — the case reads the row's *last* field (`scripts/verify.sh:453-454`), so an embedded `|` truncates the cell and fails the gate with a confusing message rather than passing silently. *Fix:* "…is the phase's last line" and "…would truncate the cell the case reads, failing the gate with a confusing message". (Also see T1: `grep -c '^ok case_'` counts a skipped case as proof.)
