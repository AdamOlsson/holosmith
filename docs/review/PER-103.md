`web/src/main.ts:2519-2529` fetches `apiPath(row.name, "sessions")` for **every** registry row, and `web/src/main.ts:816-820` draws a card for every one, with `readMachine` (`main.ts:615-619`) asking `/api/hosts/<name>/health` and `/api/hosts/<name>/sessions`. Smallest fix: gate the fan-out on the function that already exists and is already tested — `forwards(health.role)` (`transcript.ts:774`) — in one place, e.g. `const remote = forwards(health.value.role) ? hosts.value.hosts.filter(…) : []` at `main.ts:2519` and the same predicate around the card loop at `main.ts:816`, plus `navLinks`/`header` dropping the Computers link where `!forwards(role)`; one sentence in D3 recording that a machine that forwards nothing groups only itself; one `transcript.test.ts` case for the rule.
