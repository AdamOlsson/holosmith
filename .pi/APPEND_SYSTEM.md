# Linear scope (this repository)

All Linear work in this repository belongs to the project **Holosmith** (`P-HOL-2`, team `Holosmith`/`HOL`). No other Linear project is in scope. Issues created before the move carry `PER-*` identifiers and belong to the same project, so they are in scope too.

- Every `list_issues` and `save_issue` call MUST carry `project: "Holosmith"`.
- Do not query, create, or modify issues outside that project. `VulkanRenderAPI` is out of scope and must be ignored entirely.
- A Linear call that cannot be scoped to Holosmith is a blocker to report to the user, not a call to make.
